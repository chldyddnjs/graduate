# 🏋️ 홈트 도우미 - AI 운동 자세 분류 시스템

> 2021 HKNU BRIGHT MAKERS EXPO 출품작 | 국립한경대학교 소프트웨어융합전공 | 학점 A

## 프로젝트 개요
코로나로 홈트레이닝 수요가 급증하는 상황에서, 혼자 운동할 때 자세가 잘못됐는지 
판단하기 어려운 문제를 해결하기 위해 개발한 AI 기반 운동 자세 분류 앱입니다.

## 시스템 구조
카메라 입력 → PoseNet(스켈레톤 좌표 추출) → 분류 모델 → 자세 판별 → Android 탑재

## 기술 스택
Python, TensorFlow, TFLite, PoseNet, Android

## 결과
- 약 3,000장 데이터 수집 및 학습
- 안드로이드 앱 탑재 및 실시간 자세 분류 구현
- 2021 HKNU BRIGHT MAKERS EXPO 출품 및 시연
- 학점 A
